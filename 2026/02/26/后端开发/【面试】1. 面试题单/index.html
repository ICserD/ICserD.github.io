面向大厂面试的后端八股题纲

本题单围绕你的简历经历、项目实践和常见大厂面试重点展开。每个模块不仅覆盖基础知识，还列出面试常问的难点、追问点和场景题，帮助你有针对性地准备，串联起各个知识点。你可以用它作为每次面试前的复习清单，也可以按专题系统地查漏补缺。题目数量不做限制，强调覆盖度和深度。

1 Java 基础与集合框架

1.1 集合原理与数据结构

  • HashMap 的底层结构是什么？数组、链表、红黑树如何演化？为什么负载因子默认是 0.75？
  • HashMap 在 JDK 1.7 与 1.8 的核心差异是什么？链表和红黑树转换的阈值是多少？
  • HashMap 为什么线程不安全？并发环境下会发生哪两种典型问题（数据丢失、链表形成环）？
  • ConcurrentHashMap 的底层实现是什么？JDK 1.7 分段锁与 1.8 CAS+链表/红黑树的区别？
  • LinkedHashMap 如何维持访问顺序？怎么用它实现 LRU 缓存？
  • TreeMap 采用哪种树结构？插入和删除的时间复杂度是多少？为什么红黑树适合做索引？
  • 迭代器的 fail‑fast 机制是如何实现的？有哪些容器支持 fail‑safe？
  • ArrayList 和 LinkedList 的插入、删除、随机访问时间复杂度？在实际项目中如何选择？
  • CopyOnWriteArrayList 是如何实现线程安全的？适用于什么场景？
  • Java 中的队列有哪些？PriorityQueue 的底层实现如何支持优先级？
  • 对于自定义类作为 Map 的 key，有哪些注意事项？hashCode/equals 的规范是什么？

1.2 Java 语法与基础

  • JDK 与 JRE 的区别？JDK 版本升级如 8→11→17 的主要新特性是什么？
  • 自动装箱/拆箱的底层实现是什么？什么时候会触发 NullPointerException？
  • 反射的原理是什么？通过反射创建对象和直接 new 对象有什么差别？
  • 强引用、软引用、弱引用、虚引用的定义和使用场景？
  • 序列化的机制有哪些？transient 关键字的作用是什么？
  • 泛型的本质是什么？为什么会出现类型擦除？如何使用泛型通配符？
  • 深拷贝与浅拷贝的区别？如何优雅地实现一个对象的深拷贝？
  • 装饰器模式、代理模式在 Java 中有哪些经典应用？Spring AOP 底层是如何基于代理模式实现的？

2 并发编程

2.1 线程模型与基础

  • Java 中创建线程的三种方式？实现 Runnable 与实现 Callable 有何区别？
  • 守护线程和用户线程的区别是什么？finally 中使用 System.exit() 会发生什么？
  • 线程的生命周期有哪些状态？blocked 与 waiting 的区别？
  • 线程上下文切换的成本由哪些因素构成？
  • ThreadLocal 的原理是什么？如何防止内存泄漏？项目中哪些场景适合使用 ThreadLocal？
  • Java 内存模型（JMM）的三大特性是什么？可见性、有序性、原子性如何保障？
  • synchronized 关键字的底层实现是什么？锁膨胀过程（偏向锁→轻量级锁→重量级锁）是如何实现的？

2.2 原子操作与锁

  • CAS 算法的原理是什么？CAS 失败后怎么处理？ABA 问题是什么，怎么解决？
  • AQS（AbstractQueuedSynchronizer）框架的核心设计是什么？基于 AQS 的常见同步器有哪些（如 ReentrantLock、Semaphore、CountDownLatch、CyclicBarrier）？
  • 公平锁和非公平锁的区别是什么？在实际业务中如何选择？

  • 自旋锁是什么？什么情况下适合自旋？CAS + 自旋会导致什么问题？
  • 乐观锁与悲观锁的概念及实际场景对比？如何利用版本号实现乐观锁？

2.3 线程池与任务调度

  • Java 线程池的核心参数有哪些？核心线程数、最大线程数、队列大小、拒绝策略分别有什么作用？
  • 工作队列的不同实现（ArrayBlockingQueue、LinkedBlockingQueue、SynchronousQueue）适用于什么场景？
  • 如何正确关闭线程池？shutdown 与 shutdownNow 的差别是什么？
  • 自定义线程池时如何设置合理的线程数？如何防止任务堆积和 OOM？
  • 项目中的导出任务/计算任务如何利用线程池二级队列进行调度？你在 AIA 实习中如何调整线程池参数？
  • 定时任务调度框架（如 Java Timer、ScheduledExecutorService、Quartz、xxl-job）的特点与区别？在中国电信项目中如何实现高精度、高负载任务调度？

2.4 并发容器与场景实践

  • ConcurrentHashMap 为什么不需要加锁即可实现线程安全？如何在高并发情况下使用 putIfAbsent 构建本地缓存？
  • CopyOnWriteArrayList 和 ConcurrentLinkedQueue 的使用场景是什么？写多读少的情况下如何选择？
  • ArrayBlockingQueue 与 LinkedBlockingQueue 的实现区别？为什么前者能够控制队列长度？
  • 在导出报表 OOM 问题的解决方案中，如何利用单机互斥锁 + 缓存预热提升整体吞吐？
  • 多实例并行计算时如何保证任务分片的均衡性？如何利用线程池隔离不同类型的计算任务？
  • 在微服务架构下如何避免雪崩效应？熔断限流隔离的实现原理是什么？

  • 适配器模式如何解耦底层搜索引擎的差异？举例说明你在聚合搜索中的应用。
  • 搜索建议 (autocomplete) 、相关度排序、自定义评分 (script score) 如何实现？
  • 在集群部署环境下，如何处理搜索缓存更新？为什么建议使用 ElasticSearch 的事务日志监听或消息中间件同步？

9 设计模式与代码可维护性

  • 单例模式有哪些实现方式？双重检查锁与枚举实现有何区别？
  • 工厂模式、简单工厂模式、抽象工厂模式分别适合什么场景？在简历项目中是否存在“工厂”的应用？
  • 策略模式和模板方法模式的区别是什么？在你的导出/计算模块中，如何用策略模式支持不同导出格式？
  • 门面模式 (Facade) 如何降低客户端与子系统之间的耦合？你在聚合搜索中是如何封装多个搜索源的？
  • 适配器模式与装饰器模式的区别？在对接第三方 API 或兼容旧系统时如何选择？
  • 注册器 (Registry) 模式与观察者 (Observer) 模式在业务扩展场景如何应用？
  • 建造者模式在创建复杂对象（如行程规划、请求上下文）时如何提高代码可读性？
  • 在 VoyaPlan 项目中，如何使用设计模式降低圈复杂度？具体举例。

10 数据结构与算法

  • 面试常考数据结构：链表反转、环形链表、二叉树遍历、堆排序、快速排序等，需要熟练手写并分析时间复杂度和空间复杂度。
  • 常用算法思想：双指针、滑动窗口、分治、贪心、动态规划、回溯等。需要结合 LeetCode 热题 100 进行练习。重点掌握链表合并/排序、二叉树最大路径和、最长子串、不含重复字符的最长子串、数组中的第 K 大元素、LRU 缓存实现等。
  • 算法题的拓展追问：如何优化空间复杂度？能否进一步降低时间复杂度？边界条件和输入规模如何影响程序？
  • 在调度平台项目中，如何将任务队列模型抽象为数据结构问题？可以将任务按时间区间划分优先级队列吗？
  • 结合 AI 规划项目，如何将路径规划抽象为最短路径问题？A* 算法、Dijkstra 算法的实现及时间复杂度？

11 计算机网络

  • TCP 三次握手的具体流程是什么？为什么不是两次或四次？四次挥手为什么要等待两倍 MSL？
  • TCP 与 UDP 的主要区别是什么？为什么实时视频常用 UDP？
  • HTTP 与 HTTPS 的差别是什么？SSL/TLS 握手过程有哪些阶段？如何保证证书的安全性？
  • 常见的 HTTP 状态码含义：301/302 重定向、401/403/404、500 等。GET、POST、PUT、DELETE 的区别？
  • keep-alive 机制是如何工作的？长连接对服务器有哪些影响？
  • HTTP1.1、HTTP2、HTTP3 之间的差异是什么？HTTP2 为什么能实现多路复用？
  • Nginx 的反向代理和负载均衡原理？常用的负载均衡算法有哪些？为什么需要在 API Gateway 前再部署 Nginx？
  • CDN 的作用和原理是什么？DNS 解析流程及 DNS 缓存策略？
  • Websocket 与长轮询的区别？如何在后端实现消息推送？
  • 在导出或搜索场景下如何进行请求幂等设计？如何通过幂等 token 和乐观锁避免重复提交？

12 操作系统

  • 进程与线程的区别和联系？切换过程发生了哪些操作？为什么线程切换比进程切换更轻量？
  • 程序运行时的地址空间布局是什么？代码段、数据段、堆、栈分别做什么？
  • 虚拟内存的概念是什么？页表、多级页表如何映射虚拟地址到物理地址？
  • 缺页中断（page fault）与 page cache 的区别？操作系统如何利用 page cache 减少磁盘访问？你为什么在项目里不需要专门管理 page cache？
  • 进程通信方式有哪些？管道、共享内存、消息队列、信号量等如何选择？
  • Linux IO 模型有哪些？阻塞/非阻塞、同步/异步、IO 多路复用、信号驱动等。epoll 与 select 的区别？
  • 死锁产生的四个必要条件是什么？如何避免死锁？有什么经典算法检测死锁？
  • 调度算法如时间片轮转、优先级调度、短作业优先的优缺点？
  • COW（写时复制）的应用场景？fork 后子进程共享哪些数据？

13 系统设计与场景题

本节列出与简历经历相关的高并发场景设计题目，这些问题能够检验你对分布式系统整体把控能力。回答此类问题时要覆盖到需求分析、总体架构、分层设计、核心数据结构、状态管理、扩展性与容错等方面。

13.1 报表导出与大文件处理

  • 如何设计一个支持千万级数据导出的大报表系统？从数据查询、缓存、分批写入、并行处理到文件合并的链路该如何设计？
  • 单机内存有限，如何避免在导出时发生 OOM？流式处理和分批加载的代码框架如何组织？
  • 多机部署下如何避免并发导出争抢资源？单机互斥锁、分布式锁的方案如何选择？
  • 如何预生成报表缓存文件？缓存的生命周期如何管理？缓存失效/更新策略是什么？
  • 大文件导出时如何保证多线程写文件的顺序？如何处理异常重试？

13.2 任务调度与时间轮

  • 设计一个支持秒级精度、高并发触发的任务调度系统，如何在存储层分为冷数据（MySQL）与热数据（Redis）？
  • 调度系统的时间轮 / 延时队列模型如何实现？任务分片与分布式协调如何做？
  • 高峰时段如何避免调度中心成为瓶颈？如何扩展为多调度实例，保证任务不重复执行又不漏执行？
  • 如何实现任务的失败重试和幂等性？任务重试队列和死信队列如何设计？

13.3 聚合搜索与推荐系统

  • 如何设计一个聚合搜索框架，支持多种数据源（MySQL、ES、爬虫等）并返回统一格式？
  • 高并发搜索如何优化性能？缓存策略、降级策略分别怎么做？
  • 如果某个数据源挂了，聚合接口如何快速容错并返回部分结果？
  • 如何为搜索结果构建权重模型？利用 ES 的 score 与人工权重融合的方式有哪些？
  • 如何接入向量检索（RAG）提升搜索结果的相关性？当向量检索结果与关键字检索冲突时，如何做综合排序？

13.4 AI 智能规划与 RAG

  • 设计一个 AI 行程规划系统，用户输入城市和偏好，系统输出可执行的行程计划。你的系统应包括哪些模块？
  • RAG（Retrieval-Augmented Generation）的流程是什么？文档向量化、向量存储、向量检索、结果归一化、模型生成分别如何实现？
  • 如何选择合适的向量数据库（pgvector、Qdrant 等），考虑性能和成本？
  • 如何设计 Prompt 模板，使得模型输出结构化 JSON？如何避免幻觉并提供引用源？
  • 向量检索的召回与重排序如何做？在计算预算有限时，如何平衡召回率和吞吐量？
  • AI 规划服务如何与行程 CRUD 服务解耦？如何保证生成的草稿版本在用户确认前不污染主表数据？
  • 如何控制 AI 调用的并发量和成本？限流、缓存与异步任务如何配合？

13.5 高并发服务与限流降级

  • 设计一个电商秒杀系统，需要考虑哪些方面（库存扣减、超卖控制、抢购排队、限流与熔断、消息通知）？
  • 如何设计一个短链接服务？如何保证生成链接的唯一性、短链接的高并发访问和落库性能？
  • 如何设计一个大规模点赞/收藏系统？数据模型如何设计，如何解决热点 Key 问题？
  • 微服务链路如何实现全局幂等？幂等 token、业务主键、唯一索引、重试策略如何组合使用？
  • 如何设计一个自适应限流系统，既能保护核心服务，又能让更多低优先级请求降级？

14 AI 与 RAG 专题（可作为简历亮点）

  • LLM 基础：大模型的输入/输出是什么结构？Token 的概念是什么？为什么中文分词困难？
  • Embedding（向量化）原理：如何将文本转换为向量？常用的文本向量模型有哪些？向量维度会影响什么？
  • 向量数据库的索引结构：HNSW、IVF、PQ 等索引结构的原理和适用场景？
  • RAG Pipeline：数据准备 → 文档分块 → 向量化 → 检索 → 构建 Prompt → LLM 调用 → 回答整合 → 引用来源。每一步你都做了什么？
  • 如何做知识库的实时更新？文档上传后如何同步向量库？如何异步处理向量化避免影响用户体验？
  • Function Calling / Tool Calling 机制是什么？你在行程规划中定义了哪些工具函数？如何确保模型按照 schema 返回结构化结果？
  • Prompt 工程：如何写好 System Prompt、User Prompt、Function Prompt？如何在 prompt 中加入约束，要求模型输出行程 JSON？
  • 评估指标：如何评估智能行程规划的效果？基于规则的可行性检查（时间、距离、预算）、用户反馈循环如何闭环？
  • 多模态融合：未来如何将地图/图片/评论/天气等多源数据融入 RAG？

使用建议

  1. 按主题刷题：每天针对 1～2 个模块进行输出练习。先尝试自己讲解，再查阅资料弥补薄弱点。
  2. 结合项目场景：在回答八股时结合自己的项目经历，例如报表导出、调度平台、旅游规划系统等，展示落地实践和优化思路。
  3. 模拟面试：选取场景题进行系统设计演练，关注需求分析、核心数据结构、数据一致性、容错方案以及上线演练等。
  4. 动态维护：随着学习和面试经历持续补充题目和知识点，形成自己的知识体系。
