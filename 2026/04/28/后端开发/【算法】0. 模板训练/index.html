Java 后端校招算法 14 天提速计划

使用方法

  • 每天直接打开对应 Day，按顺序勾选
  • 每天总时长约 3 小时
  • 训练结构固定：模板默写 40 分钟 + 限时刷题 100 分钟 + 复盘重写 40 分钟
  • 目标不是刷更多题，而是：模板打牢、手写提速、旧题回炉

统一执行规则

每天开始前

  1. 开始前先看昨天的“最卡题”和“慢因”

  2. 开始前先确定 1 道“明日回炉题”

  3. 做题时统一变量命名，不临场乱改

  4. 至少有 2 道题必须独立限时完成

  5. 至少有 1 道题要做脱稿重写

每题执行步骤

  1. 先判断题型

  2. 口述 30 秒思路

  3. 再开始写代码

  4. 写完手动过样例

  5. 记录耗时

  6. 复盘慢因

  7. 必要时脱稿重写

限时标准

  1. Easy 控制在 8~12 分钟

  2. Medium 控制在 15~20 分钟

  3. 超过 20 分钟先停，进入复盘

今日模板默写（40 分钟）

二分算法

二分其实有两种思维方式：

  1. 找某个数，可能不存在
  2. 找边界（左边界/游边界）

普通二分

普通二分就是找某个数，这个数可能不存在

边界二分

边界其实指的是 target 值在有序数组中的边界，这里假设有序数组是递增的

  • 左边界：有序数组中第一个等于 target 的位置，也有可能不存在等于 target 的位置，因此左边界等价于第一个 >= target 的位置
  • 右边界：有序数组中最后一个等于 target 的位置，也有可能不存在等于 target 的位置，因此右边界等价于最后一个 <= target 的位置
左边界二分
右边界二分

快慢指针

核心思想，快指针每次移动 n 步，慢指针每次移动 m 步，m < n。

应用方向：

  1. 判环
  2. O(N) 找到链表倒数第 k 个节点

应用一：找中点

核心思想：快指针走 2 步、慢指针走 1 步，快指针到终点时慢指针正好处于中点。

  • [ ] 我今天有没有至少 2 道题是独立限时写出来的？
  • [ ] 我今天有没有 1 道旧题写得比上次更快？

这 14 天不追求刷得多，
只追求：模板能默写，母题能限时，旧题能提速。
